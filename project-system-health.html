System Health Checker

A Python-based diagnostics tool for CPU, RAM, disk usage, and system uptime.

Python psutil Automation System Monitoring

Overview

The System Health Checker is a command-line tool designed to help users and IT technicians quickly understand the current state of a system. It collects CPU usage, RAM utilization, disk space, and uptime, then presents the results in a clear, readable format.

This project reflects my focus on practical troubleshooting tools — the kind of utilities that make diagnosing performance issues faster, more consistent, and less stressful.

Key Features

  • Real-time CPU usage reporting
  • RAM utilization and available memory
  • Disk usage per partition
  • System uptime calculation
  • Clean, readable CLI output
  • Error handling for missing permissions or modules

Tech Stack

  • Python 3
  • psutil for system metrics
  • Standard library platform and time
  • Runs on Windows and Linux

How It Works

The tool gathers system metrics using psutil and other standard libraries, then formats the results into a structured report. Each check is handled by a dedicated function, making the script easy to extend and maintain.

Code Snippet


import psutil
import time

def get_cpu_usage():
    return psutil.cpu_percent(interval=1)

def get_ram_usage():
    mem = psutil.virtual_memory()
    return mem.percent, mem.used, mem.total

def get_uptime():
    boot_time = psutil.boot_time()
    seconds = time.time() - boot_time
    hours = int(seconds // 3600)
    minutes = int((seconds % 3600) // 60)
    return hours, minutes

if __name__ == "__main__":
    cpu = get_cpu_usage()
    ram_percent, ram_used, ram_total = get_ram_usage()
    hours, minutes = get_uptime()

    print("System Health Report")
    print("--------------------")
    print(f"CPU Usage: {cpu}%")
    print(f"RAM Usage: {ram_percent}%")
    print(f"Uptime: {hours} hours {minutes} minutes")

Challenges & Solutions

  • Cross-platform behavior: handled differences in disk naming and permissions.
  • Accurate uptime: used psutil.boot_time() instead of manual tracking.
  • Readable output: iterated on formatting to make the report easy to scan quickly.
