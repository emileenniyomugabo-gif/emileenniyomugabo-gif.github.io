Overview

The System Health Checker is a Python-based diagnostic tool that analyzes CPU usage, RAM utilization, disk space, and system uptime. It provides a clear snapshot of system performance and offers basic optimization suggestions.

This project reflects my focus on practical troubleshooting tools — the kind of utilities that make diagnosing performance issues faster, more consistent, and less stressful.

Features

  • Real-time CPU usage monitoring
  • Memory and disk usage analysis
  • System uptime tracking
  • Readable, color-coded console output
  • Lightweight and fast execution

Technologies Used

  • Python 3
  • psutil library
  • Standard system utilities
