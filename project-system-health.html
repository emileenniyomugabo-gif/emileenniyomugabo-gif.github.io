System Health Checker

A Python tool that analyzes system performance, checks disk usage, memory, CPU load, and provides optimization suggestions.

Overview

The System Health Checker is a lightweight diagnostic tool designed to help users quickly understand the current state of their computer. It gathers essential system metrics and presents them in a clear, readable format. This project demonstrates Python scripting, system monitoring, and practical IT support skills.

Key Features

  • Real-time CPU usage monitoring
  • Memory and disk usage analysis
  • System performance summary
  • Optimization suggestions based on thresholds
  • Clean, readable console output

Technologies Used

  • Python 3
  • psutil library
  • Standard system utilities
