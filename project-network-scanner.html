Overview

The Network Scanner is a Python tool that detects active devices on a network, identifies open ports, and highlights potential security risks. It provides quick visibility into what’s happening across a local network without relying on heavy enterprise tools.

This project strengthened my understanding of networking fundamentals, socket programming, and how devices communicate across a LAN. It also helped me practice writing clean, modular code for real-world troubleshooting tasks.

Key Features

  • Scans a full IP range for active devices
  • Detects open ports on each device
  • Identifies common service ports (HTTP, SSH, RDP, etc.)
  • Fast multi-threaded scanning
  • Clean, readable CLI output
  • Error handling for unreachable hosts

Technologies Used

  • Python 3
  • sockets for network communication
  • threading for fast scanning
  • Runs on Windows, Linux, and macOS
