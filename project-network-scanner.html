Network Scanner

A Python tool that scans devices, ports, and basic vulnerabilities across a network.

Python Sockets Networking Automation

Overview

The Network Scanner is a lightweight Python tool designed to detect active devices on a network, identify open ports, and highlight potential security risks. It’s built for IT technicians who need quick visibility into what’s happening on a local network without relying on heavy enterprise tools.

This project strengthened my understanding of networking fundamentals, socket programming, and how devices communicate across a LAN. It also helped me practice writing clean, modular code for real-world troubleshooting tasks.

Key Features

  • Scans a full IP range for active devices
  • Detects open ports on each device
  • Identifies common service ports (HTTP, SSH, RDP, etc.)
  • Fast multi-threaded scanning
  • Clean, readable CLI output
  • Error handling for unreachable hosts

Tech Stack

  • Python 3
  • sockets for network communication
  • threading for fast scanning
  • Runs on Windows, Linux, and macOS

How It Works

The scanner sends connection attempts to a range of IP addresses and ports. If a device responds, it is marked as active. For each active device, the tool checks a list of common ports to identify running services.

Code Snippet


import socket
import threading

def scan_port(ip, port):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.3)
    try:
        s.connect((ip, port))
        print(f"{ip}:{port} OPEN")
    except:
        pass
    finally:
        s.close()

def scan_ip(ip):
    print(f"Scanning {ip}...")
    common_ports = [22, 80, 443, 3389]
    for port in common_ports:
        threading.Thread(target=scan_port, args=(ip, port)).start()

if __name__ == "__main__":
    base_ip = "192.168.1."
    for i in range(1, 50):
        scan_ip(base_ip + str(i))

Challenges & Solutions

  • Slow scanning: solved with multi-threading.
  • Timeout issues: optimized socket timeout values.
  • False positives: added retry logic for unstable hosts.

What I Learned

  • How to use Python sockets effectively.
  • The importance of efficient threading in network tools.
