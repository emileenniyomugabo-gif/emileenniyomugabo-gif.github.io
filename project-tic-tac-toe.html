Overview

This Tic Tac Toe game is a clean, interactive two-player experience built with HTML, CSS, and JavaScript.

It demonstrates DOM manipulation, game logic, event handling, and UI design fundamentals.

Features

  • Two-player game logic
  • Win and draw detection

  • Clean board layout

Technologies Used
